# Graphics

## Rules

- **No comments.** Never add comments to code (Jai, Slang, build scripts). When editing a line that has a comment, drop the comment rather than rewriting it. Explanations go in the conversation, not the source.
- **Commit messages are a subject line only.** No body, beyond any required attribution trailer.
- **Launch with the `run` skill.** Every execution of the program uses `-automation` so the window never takes focus.
